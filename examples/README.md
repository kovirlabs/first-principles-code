# Worked examples

Each script answers one realistic engineering question from start to finish.
Read the docstring at the top (QUESTION / APPROACH), run it, then change the
inputs. Figures and tables go to `examples/output/` (git-ignored).

```bash
uv run examples/pump_sizing.py
```

| Script | Question | Python ideas it shows |
| --- | --- | --- |
| [`pump_sizing.py`](pump_sizing.py) | Which pipe size and pump for 12 L/s up 15 m? | Root finding (Colebrook), property interpolation, dict loops, system-curve plot |
| [`beam_selection.py`](beam_selection.py) | Lightest W-beam for a 6 m span, 40 kN load? | Pint unit conversion (SI to US catalogue), pandas filtering and sorting |
| [`pid_tuning.py`](pid_tuning.py) | Which PI gains settle fastest with less than 5% overshoot? | Grid search, NumPy boolean masks, `min(key=lambda ...)` |
| [`heat_exchanger_estimate.py`](heat_exchanger_estimate.py) | Duty and area of a water-to-water exchanger? | Energy balance, fixed-point iteration, LMTD |
| [`motor_sizing.py`](motor_sizing.py) | Which servo motor fits a ball-screw axis? | Motion profiles, RMS torque, screening a list of dicts with `all()` |
| [`shielding_check.py`](shielding_check.py) | Lead vs concrete thickness for 0.1% transmission? | Attenuation, HVL/TVL, inverse square law |
| [`sensor_log_analysis.py`](sensor_log_analysis.py) | Operating points and alarm times from a pump log? | pandas: read, clean, group, resample, mask, export to Excel |
| [`vectorization.py`](vectorization.py) | Which of 1,000,000 load cases exceed yield? | Loops vs NumPy, broadcasting, boolean masking, timing |
| [`radiology_demo.py`](radiology_demo.py) | Tour of the medical-imaging classes | pydicom, CT windowing, matplotlib subplots |

`data/pump_sensor_log.csv` is **synthetic**, generated by
`data/make_pump_sensor_log.py` with a fixed random seed.

Starting your own problem? Copy [`templates/engineering_script.py`](../templates/engineering_script.py).
